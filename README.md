# 📊 Superstore Interactive Dashboard – Power BI

##  Project Overview
This project presents an interactive Superstore Sales Dashboard developed using **Microsoft Power BI**. It provides a visual overview of sales performance, trends, categories, regions, shipping modes, and product-level insights.

The dashboard helps users explore business data interactively and understand sales patterns through visual analytics.

##  Dashboard Highlights

- **Total Sales:** 2.26M
- **Average Sales:** 0.23K
- **Count of Sales:** 9,800
- **Sum of Row ID:** 48M

##  Dashboard Features

- Year-wise filtering (2015–2019)
- City and Region slicers
- Sales analysis by category
- Customer-level sales comparison by region
- Shipping mode analysis
- Monthly sales trend visualization
- Sub-category sales performance
- Product-wise Postal Code count analysis

## Project Objective

The objective of this project is to transform raw Superstore data into an interactive dashboard that makes business performance easier to analyze and helps users explore trends and patterns across multiple dimensions.
